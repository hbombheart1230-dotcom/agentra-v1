# C03 — 작업 배정

기존 매시 00분 예약으로 실행한다. 정본 integration/p1.5의 D00와 이 파일을 읽는다. 입력은 #11/#12/#32 및 #36의 신규 증거다. 스킬은 agentra-contract-guard다.

## 실행 순서
1. 정본·A·B HEAD와 C01/C02 주문의 미완료·진행 중·원격 완료 상태를 확인한다.
2. 미완료 RF의 최초 미충족 게이트를 확인해 A/B 각각 수행 가능한 작업을 찾는다. 한 RF의 HOLD로 전체 후보 탐색을 끝내지 않는다.
3. G1/G2를 해소할 항목은 ORDER_ID, ITEM, RF, FIRST_UNMET, 허용 경로, SOURCE/TARGET blob, 관련 테스트, 완료 조건을 명시해 C01/C02에 발행한다. 교차 파일 중복 배정 금지. 8~10개 공급 및 예비 6개 강제 없음.
4. G3만 남으면 C04로, 모든 게이트 충족 시 C05로 인계한다. 모든 독립 안전 후보를 처리하고 차단별 담당·해소 조건을 기록한다.
5. 작업서를 원격 갱신하고 blob을 재조회한 뒤 #36에 새 주문과 인계를 보고한다.

## 현재 처리 대상
- B44 RF-063은 C01에 발행됨. #12 결과가 실패면 최소 수정 범위를 확정하고, 통과면 C04 정본 소비 경로 검증으로 연결한다.
- A57 완료 여부를 #11에서 확인하고 A의 다음 미완료 게이트 작업을 발행한다.
- RF-030은 C04의 현재 소비 경로 검증 범위 및 RF-074 frozen scope 판정을 받아 다음 조치를 정한다.
- RF-026/032/065는 Owner·보호 경계를 확인하고 허용된 독립 작업을 계속한다.
- PC 담당 모델 원복·PR40/41 결과를 확인해 중복 작업을 방지한다.

완료 주문 재발행 및 근거 없는 NO_READY_ORDER 반복 금지. 문서 갱신이나 BODY MOVE 개수를 RF DONE으로 계산하지 않는다.
