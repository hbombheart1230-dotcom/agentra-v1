2026-11-03 홍사장 직접 승인 — FAST-3 DONE-FIRST 정책 (최상위 우선)

본 절은 기존 D00의 8~10개 신규 BODY MOVE 강제 공급, Actor별 예비 6개 의무 및 C01~C06 작업서의 관련 수량 지침에 우선한다.

1. 최우선 목표

Agentra P1.5의 최우선 성과는 신규 RF DONE 증가다.

실제 G1/G2/G3 게이트를 닫는 작업을 단순 BODY MOVE 개수보다 우선한다.

2. C03 신규 작업 공급

- 신규 작업은 8~10개를 강제로 채우지 않는다.
- FIRST_UNMET G1/G2를 해결할 수 있는 검증된 안전 작업이 1건이라도 있으면 즉시 C01/C02에 배정하고 원격 푸시한다.
- 예비 작업 6개 확보는 권장 목표로 변경하며, 부족하다는 이유로 실행 가능한 작업을 지연하지 않는다.
- "GATE_IMPACT=NO"인 구조개선 작업은 실제 게이트 해결 작업보다 후순위로 배정한다.
- 실행 가능한 작업이 없으면 RF 번호, 정확한 차단 원인, Owner, 증거 SHA 및 다음 해결 조치를 보고한다.
- 이미 완료된 작업의 재발행과 허위 신규 실적은 금지한다.

3. C04 통합 및 G3

C04는 신규 A/B BODY MOVE를 기다리지 않고 기존 G1/G2 증거가 있는 RF의 G3 검증을 우선 수행한다.

우선 검토 대상은 RF-030의 정본 fake smoke와 RF-063의 resolver/consumer 정합성이다.

실제 검증 없이 G3 PASS를 선언하지 않는다.

4. C05 RF DONE

C05는 G1/G2/G3를 모두 충족한 RF를 즉시 실제 RF 문서 및 STATUS에 반영하여 DONE 처리한다.

정책 HOLD나 승인 미확보 RF는 임의 종결하지 않는다.

5. C06 감사 기준

C06은 다음 항목을 구분하여 감사한다.

- 신규 RF DONE 증가
- 실제 G1/G2/G3 게이트 해소
- 게이트 해결에 직접 기여한 코드 변경
- 게이트와 무관한 BODY MOVE
- 증거가 확인된 실제 작업 공급 실패

기존 8~10개 공급량 또는 예비 6개 부족만으로 C03을 실패 처리하지 않는다.

6. 기존 계약 보존

다음 규칙은 변경하지 않는다.

- FAST-3 G1/G2/G3 실제 증거 요건
- Owner 및 파일 독점권
- frozen oracle과 기존 테스트 계약
- Guard, Writer, UEF, Step5C 및 실거래 안전 제한
- A/B 코드 개발, C03 작업 배정, C04 통합, C05 DONE, C06 감사의 역할 분리
- 기존에 시작된 유효 작업의 소급 취소 금지

충돌 시 본 절의 DONE-FIRST 공급 우선순위를 적용하되, 안전·검증·권한 제한은 완화하지 않는다.
